# 棋盘与坐标约定

> 本页是实现细节附录。训练和演示时只需要知道五子棋棋盘是 15 x 15，落子位置可以用行列坐标表示。

## 棋盘表示

棋盘使用二维数组表示：

```text
board[y][x]
```

默认棋盘大小：

```text
15 x 15
```

棋子数值：

```text
0  = 空位
1  = 黑棋
-1 = 白棋
```

坐标从 `0` 开始：

```text
x = 横坐标，范围 0 到 14
y = 纵坐标，范围 0 到 14
```

## row/col 与 x/y

系统内部统一认为：

```text
x = 列
y = 行
```

Godot 或部分接口也会使用：

```text
row = y
col = x
```

MoveEngine 可以输出 `x/y`，也可以输出 `row/col`。本地推理服务会归一化为 `x/y` 后再返回给上层。
