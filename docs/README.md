# 五子棋 AI 训练与博弈 Workshop

这份文档面向 Workshop 参与者和项目展示观众。阅读时不需要理解服务器、客户端或协议实现；只要打开发布好的网页即可。

本项目的核心内容是：

- 训练一个会下五子棋的 AI。
- 用规则 Bot 或其他模型作为对手进行博弈。
- 通过可视化客户端观察模型行为和对局结果。
- 由对局结果反过来理解强化学习、PPO、奖励设计和评估方法。

## 你需要重点掌握什么

优先看这些内容：

1. 强化学习为什么适合描述“通过对局变强”的过程。
2. PPO 如何让策略更新更稳定。
3. 五子棋如何被建模成 state、action、reward。
4. 如何评估一个五子棋 AI 是否真的变强。

服务器、客户端、WebSocket、MoveEngine 协议等内容只是为了让项目跑起来和展示出来。它们不是本项目需要重点掌握的知识点，已经放到“附录：实现细节”。

## 推荐阅读顺序

1. [如何阅读与体验](guide/quick-start.md)：了解这个项目展示什么。

## 对外展示方式

参与者只需要访问文档网页，不需要安装文档工具链。维护者可以把 `docs/` 目录部署为静态站点，例如 GitHub Pages、Nginx 静态目录或其他静态托管服务。
