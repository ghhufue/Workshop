# 五子棋 AI 强化学习 Workshop

这份文档围绕一个五子棋 AI 训练项目展开。它不是只展示最终模型，而是把训练过程拆成多个阶段：先理解强化学习的基本概念，再理解 PPO，最后观察模型在不同训练设计下如何变化。

阅读时可以先忽略服务器、客户端和协议细节。它们负责让项目跑起来和展示出来，但本 workshop 的主线是强化学习训练本身。

## 这份文档讲什么

你会看到一条从基础到完整训练流程的路线：

```text
强化学习基础
  -> PPO 算法
  -> 五子棋环境建模
  -> 终局奖励与稀疏反馈
  -> Action Mask
  -> 人工棋形奖励
  -> 奖励退火
  -> 混合对手与历史模型对手
  -> 评估与可视化观察
```

对应到代码训练阶段：

| 阶段 | 重点问题 |
|---|---|
| V0 | 怎样把五子棋变成强化学习环境 |
| V1 | 只靠输赢奖励能不能学 |
| V2 | 为什么需要 action mask |
| V3 | 人工棋形奖励怎样缓解稀疏奖励 |
| V4 | 为什么人工奖励不能一直很强 |
| V5 | 为什么不能只和一种 Bot 训练 |
| V6 | 历史 checkpoint 对手有什么作用 |

## 重点问题

读这份讲义时，建议一直带着这些问题：

1. 模型到底是在学习规则，还是在学习策略？
2. 为什么不能直接根据 reward 正负更新参数？
3. 优势函数为什么比单步 reward 更适合指导 PPO 更新？
4. 终局奖励为什么目标清晰但训练困难？
5. 人工棋形奖励为什么有用，又为什么可能把模型带偏？
6. 为什么 loss 下降不等于棋力变强？

## 推荐阅读顺序

1. [如何阅读与体验](guide/quick-start.md)：先了解这个项目展示什么。
2. [安装说明](guide/installation.md)：如果要在本机运行项目，先完成仓库、Python、PyTorch 和 Godot 安装。
3. [强化学习基础](workshop/rl-intro.md)：建立 RL 的基本概念。
4. [PPO 算法](workshop/ppo.md)：理解 Value、Advantage、Actor-Critic 和 PPO Clip。
5. [五子棋建模与训练阶段](workshop/gomoku-rl.md)：按 V0 到 V4 理解环境、稀疏奖励、mask、棋形奖励和退火。
6. [训练后期与评估](workshop/training-evaluation.md)：理解混合对手、历史模型对手、评估和可视化观察。
7. [演示界面说明](guide/godot-client.md)：了解展示时客户端里看到的内容。

## 可以先跳过什么

如果你只是参加 workshop 或阅读讲义，可以先跳过：

- Match Server 协议。
- MoveEngine JSON Lines 协议。
- Godot 客户端内部实现。
- 本地推理服务内部流程。

这些内容放在附录里，主要给后续维护者或想接入自己模型的人参考。

## 对外展示方式

参与者只需要访问文档网页，不需要安装文档工具链。维护者可以把 `docs/` 目录部署为静态站点，例如 GitHub Pages、Nginx 静态目录或其他静态托管服务。
