# 如何阅读与体验

本页面向 Workshop 参与者。你不需要先了解服务器、客户端或协议实现。打开发布好的网页后，按左侧目录阅读即可。

## 这个项目展示什么

项目展示的是“训练五子棋 AI，然后让 AI 进行博弈”的完整思路：

1. 把五子棋转换成强化学习问题。
2. 用 PPO 训练一个落子策略。
3. 让模型和规则 Bot 或其他模型对局。
4. 通过胜率、非法动作、平均对局长度等指标评估训练效果。
5. 用图形界面观察模型在真实棋盘上的表现。

## 先看哪些内容

建议先看讲义部分：

- [强化学习基础](../workshop/rl-intro.md)

## 演示时会看到什么

演示界面通常会展示：

- 选择线下或线上对局模式。
- 选择本地模型、checkpoint 或调试用随机引擎。
- 黑白双方在棋盘上自动落子。
- 对局结束后展示胜负结果。

你可以把客户端理解成“观察 AI 对局的可视化工具”。它帮助展示模型行为，但不是讲义的重点。

## 哪些内容可以跳过

如果你只是参加 Workshop 或阅读项目讲义，可以跳过：

- Match Server 协议。
- MoveEngine JSON Lines 协议。
- Godot 客户端内部实现。
- 本地推理服务内部流程。

这些内容放在附录里，主要给后续维护者或想接入自己模型的同学参考。

## 想自己运行项目时

如果你想在自己的电脑上复现演示，需要 Python 环境和 Godot。具体启动命令放在 [运行与排错](runbook.md)，这部分不是普通读者必须掌握的内容。
