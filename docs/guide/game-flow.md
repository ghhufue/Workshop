# 线下与线上流程

> 本页用于理解演示流程，不要求掌握客户端或服务器实现。

## 线下模式

操作流程：

1. 在主菜单点击 `OFFLINE PLAY`。
2. 进入 `SELECT OFFLINE MODE`。
3. 选择一种模式。
4. 点击 `START`。
5. 在配置页选择需要的 Bot 或模型文件。
6. 点击 `START` 进入棋盘。

## Human vs Model

黑方是人类，白方是本地模型。需要选择一个模型或 MoveEngine 文件。

## Model vs Bot

黑方是本地模型，白方是规则 Bot。这个模式适合观察模型和固定规则对手的对局。

## Human vs Bot

黑方是人类，白方是规则 Bot。只需要选择 Bot 类型，不需要选择模型文件。

## 线上模式

标准联机演示流程：

1. 一方点击 `CREATE ROOM`。
2. 创建者输入昵称，点击 `START`。
3. 创建者把右上角房间号告诉另一方。
4. 另一方点击 `JOIN ROOM`。
5. 加入者输入昵称和房间号，点击 `JOIN`。
6. 双方进入同一个房间等待页。
7. 创建者点击 `START`，进入模型选择阶段。
8. 双方各自选择或填写自己的本地模型，点击 `START` 提交 ready。
9. 双方都 ready 后，创建者再次点击 `START`。
10. 进入棋盘，对局开始。

## CREATE ROOM

`CREATE ROOM` 会让创建者作为黑棋玩家进入房间。对方加入前不能开始。对方加入后，第一次 `START` 进入模型选择阶段，第二次 `START` 才真正开始棋局。

## JOIN ROOM

加入者需要输入昵称和 6 位房间号。加入成功后，客户端同步双方昵称、黑白位置和 ready 状态。

## HOST GAME

`HOST GAME` 用于创建主持房间。主持人不作为黑白棋玩家参与落子，但可以控制房间进入模型选择阶段，并在两个玩家都 ready 后开始对局。
