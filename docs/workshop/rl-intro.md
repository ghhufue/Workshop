# 强化学习基础

本讲义的目标是帮助读者从强化学习基础过渡到五子棋 PPO 实战。

核心路线：

```text
强化学习基础 -> PPO 算法 -> 五子棋问题建模 -> 训练与评估 -> 改进方向
```

## 什么是强化学习

强化学习是一种让智能体通过与环境交互来学习决策的方法。

| 学习方式 | 数据来源 | 学习目标 |
|---|---|---|
| 监督学习 | 已标注的数据 | 学会输入到输出的映射 |
| 强化学习 | 与环境交互获得奖励 | 学会最大化长期收益的策略 |

强化学习不是直接给出正确答案，而是让模型不断经历：

```text
尝试动作 -> 获得反馈 -> 调整策略 -> 继续尝试
```

## 交互框架

一个典型强化学习系统包含：

- `Agent`：智能体，负责做决策。
- `Environment`：环境，接收动作并返回反馈。

交互过程：

```text
State s_t
   ↓
Agent 根据策略 π(a|s) 选择动作 a_t
   ↓
Environment 执行动作
   ↓
返回 Reward r_t 和新状态 s_{t+1}
   ↓
Agent 根据反馈更新策略
```

## 核心概念

| 概念 | 含义 |
|---|---|
| State | 当前环境状态 |
| Action | 智能体可以执行的动作 |
| Reward | 环境返回的反馈信号 |
| Policy | 给定状态下选择动作的规则 |
| Episode | 一次完整交互过程 |

## 长期回报

强化学习关注从当前开始的长期累计收益：

```text
G_t = r_t + gamma * r_{t+1} + gamma^2 * r_{t+2} + ...
```

直觉上，好策略不是当前一步看起来最赚，而是在长期上更有利。
