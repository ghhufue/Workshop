# 五子棋强化学习建模

五子棋适合用来讲强化学习，因为规则简单、状态空间足够大、策略性强，并且结果容易可视化。

## MDP 建模

| 强化学习概念 | 五子棋中的对应 |
|---|---|
| State | 当前棋盘局面 |
| Action | 选择一个位置落子 |
| Reward | 落子后得到的奖励 |
| Policy | 给定棋盘后选择落子位置的策略 |
| Episode | 一整局五子棋对局 |

核心任务：

```text
给定当前棋盘状态，选择一个长期更有利的落子位置。
```

## 状态表示

对于 15 x 15 棋盘，可以使用多通道矩阵表示：

```text
3 x 15 x 15
```

常见通道：

| 通道 | 含义 |
|---|---|
| Channel 1 | 己方棋子位置 |
| Channel 2 | 对手棋子位置 |
| Channel 3 | 当前回合或当前玩家信息 |

这种表示保留空间结构，适合输入 CNN 网络。

## 动作设计

15 x 15 棋盘有 225 个动作：

```text
Action = 0, 1, 2, ..., 224
```

动作到坐标：

```python
row = action // 15
col = action % 15
```

## Action Mask

已经有棋子的位置是非法动作，因此必须使用 action mask。

```text
合法位置：保留 logits
非法位置：将 logits 设为极小值
再进行 softmax 或 sampling
```

没有 mask 时，模型可能频繁选择已有棋子，导致采样无效、训练信号混乱和学习效率下降。

## 奖励设计

本项目可以采用：

```text
终局奖励 + 棋形密集奖励
```

| 奖励类型 | 含义 | 示例 |
|---|---|---|
| 终局奖励 | 根据胜负结果给分 | 赢棋 +1，输棋 -1，平局 0 |
| 密集奖励 | 每一步根据棋形变化给分 | 活三、冲四、防守威胁 |

密集奖励能加快早期学习，但也可能让模型追求局部棋形分而偏离赢棋目标，因此需要做 reward ablation。
